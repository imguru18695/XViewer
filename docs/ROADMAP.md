# Roadmap

First milestone: Windows installation and PDF opening, inherited local PDF tools, export fixes, regression coverage, CI, and transparent attribution.

Reader milestone (0.2): reader-first opening, page navigation and thumbnails, fit/zoom controls, selectable text, signature-image editing, and printing of edited documents.

Next steps:

- Page rotation, bookmarks, and recent files.
- Signature-image cropping and optional background cleanup.
- Unsaved-work guard and workspace recovery (deferred).
- Persistent OCR text layers with export tests.
- Redaction fixtures for rotation, scans, annotations, nested objects, and hidden content.
- Broader form controls and explicit flattening options.
- Accessibility and keyboard navigation review.
- Authenticode signing for Windows releases.
- Compression controls and a higher-resolution/vector print path.

Existing-content editing and certificate signatures require further PDF-engine evaluation. These are plans, not current capability claims.

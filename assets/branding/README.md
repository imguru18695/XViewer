# Page Wing — XViewer branding

The selected concept combines folded document pages into an abstract X. Indigo wings sit on the left and mint wings on the right. Preserve the transparent diagonal separations and generous margins when using the mark at small sizes.

- `page-wing-concept.png`: the original approved concept card.
- `page-wing.png`: the transparent 1254px app-logo master.
- `../../build/page-wing.png`: 512px desktop PNG.
- `../../build/page-wing.ico`: Windows multi-resolution icon (seven sizes).
- `../../build/page-wing.icns`: macOS icon container.

The built-in ImageGen tool produced the concept and isolated master. The packaging tool performs only size/format conversion. Run `npm run brand:icons` to regenerate the platform icons from the approved master. The source assets are committed, so ordinary builds do not require image generation.

## Concept prompt

Use case: logo-brand. Create a polished logo concept preview for XViewer, a local desktop PDF reader and editor. Concept: 03 — Page Wing. An abstract open document with two sweeping folded pages forms a recognizable X silhouette, like a poised wing made from paper. Indigo #5754D9 and mint #59DDC2. Restrained expressive motion through two or three solid geometric surfaces, crisp flat vector-like design, no bird drawing.

Presentation: a square premium design exploration card on uniform warm off-white #F6F7F9. One large centered standalone icon taking about 45 percent of image width, generous quiet whitespace, straight-on. Below the icon display the exact wordmark "XViewer" in a modern neutral dark sans-serif, then the exact small concept label "03 — Page Wing". Only these two lines of text. Make the mark exceptionally crisp, vector-friendly, visually balanced and legible at small scale. This is a sample for choosing a logo direction, not an existing brand identity. Do not imitate Adobe, Acrobat, Microsoft, or the X social network logo. No mockup devices, photography, perspective, metallic effects, shadows, ornamental patterns, slogans, or watermarks.

## Master isolation prompt

Edit the provided XViewer '03 — Page Wing' concept card into a production app-logo asset. Preserve the exact existing four-wing folded-paper X symbol, its silhouette, the white/negative-space diagonal separations, the indigo-purple left wings, and mint-teal right wings. Remove ALL text, including XViewer and 03 — Page Wing, and remove the off-white card background completely. The ONLY remaining object must be the same Page Wing symbol, isolated on genuine transparent alpha. Recenter and enlarge the symbol to occupy approximately 80 percent of a square canvas, leaving an even transparent safety margin. Keep its geometry, proportions, subtle color treatment and crisp edges faithful to the selected concept; do not redesign or add anything. No background tile, no wordmark, no letters or labels, no cast shadow. Use case logo-brand; asset type desktop application icon master.
